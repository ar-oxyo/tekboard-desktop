# Frontend (`src/`)

- `main.tsx` : point d'entrée ; charge `CaptureApp` seul dans la fenêtre `capture`, sinon `app/App.tsx`.
- `app/App.tsx` : routeur par état (`useUi().page`, pas de router), pages lourdes en `lazy`, onboarding (`features/onboarding`) tant que `settings.onboarded` est faux ; `<main>` est un `@container` ; barre de page des sections à onglets avec `PageBarSlot`. `app/sections.ts` : 9 sections (Ctrl+1…9), `tabs: true` pour Projets, École, Labo, Connect et Réglages (onglets dans la barre de page ; École : Logtime, Crédits, Skill Tree, Sujets, MY Epitech), `pageLabel`. `app/Sidebar.tsx` : liste plate (Aujourd'hui, Projets, Planning, Inbox · École, Stats, Labo, Connect · épinglés = favoris), rail Ctrl+B (`usePref("sidebarRail")`). `app/pageIcons.tsx` (icône par page, partagée avec la palette), `app/history.ts` (Alt+←/→), `app/ShortcutsDialog.tsx` (Ctrl+/).
- Apparence : `lib/appearance.ts` (pur : mode clair/sombre/système, `data-mode` sur <html> avant le premier rendu, `crossFade`) + `useColorMode` dans `lib/hooks.ts` (pref `colorMode`, miroir localStorage). Design par défaut id `aurora` = « Riso » ; ambiances sauge/ardoise/prune/sumi (clair + sombre, `LIGHT_DESIGNS`) ; flat/neon/cozy/terminal = « Obsolètes », sombres. Prefs de confort dans hooks.ts : `useMotionPref` (pref motion), `useAutoAmbiance`, et `features/overview/` : Aujourd'hui en widgets (`layout.ts` pur et testé : disposition v2, migration v1 ; `WidgetGrid.tsx` : mode édition, glisser, tailles, ajout/retrait ; `NewWidgets.tsx`). Couleur d'accent : `lib/color.ts` (contraste) + `useAccent`, appliquée dans `main.tsx` avant le rendu. Icône de fenêtre par ambiance : `api.appSetIcon(theme)`.
- `src/dev/` : faux backend de développement (mockIPC + fixtures), chargé seulement hors Tauri en dev ; voir CLAUDE.md.
- `lib/api.ts` : TOUS les appels backend (`api.<méthode>`) + types miroirs du Rust ; son `invoke` appelle `afterCommand` → invalidation automatique.
- `lib/sync.ts` : bus de données. `COMMAND_DOMAINS` (commande → domaines), `DOMAIN_KEYS` (domaine → préfixes de clés Query), écoute `data-changed` du backend.
- `lib/hooks.ts` : `keys` + hooks Query partagés (`useSettings`, `useRepos`, `useBoard`, `usePref`, `useProjectActions`…). `lib/store.ts` : état UI zustand (`useUi` : page, toasts, demandes de lancement), type `Page`/`PAGES`.
- `lib/*.ts` purs et testés : `plan` (créneaux/charge), `brain`, `boards`, `skilltree` (galaxie : `galaxy()` constellation par bloc, étoiles en phyllotaxie, caméra `fitBox`/`starView`/`between`, molette simple laissée à la page), `charts`, `arena`, `playground`, `connect`, `share`, `repos`, `jobs`, `ai`, `format`, `i18n`, `credits` (barème PGE1 2026 ; officiel = acquis et noté, « validé, note à venir » = acquis sans note ; codes MY exacts ; pistes multiples par semestre `{ue}:{sem}` ; métadonnées du barème intégré rafraîchies à la lecture), `moderation` (+ `moderation.json` partagé avec Rust), `color`, `myFreshness`, `sessionBus` (messages Connect `space.*`/`board.*` vers les features). Champs `components/TimeField` (24 h) et `components/DateField` (JJ/MM/AAAA) au lieu des champs natifs.
- `features/` : une page ou un panneau par dossier (overview, projects + fiche `ProjectSheet`, planning, myepitech (+ `CreditsPage`, `freshness.tsx`), testing (+ `Mouli.tsx` = moulinette TekBoard), library, git, analytics, subjects, templates, prompts, settings, artix = panneau assistant, brain = Brain Dump, playground, arena, whiteboard, connect, space = TekSpace pixel art en TS pur (`avatars.tsx` 24 avatars, `spotify.tsx`, discussion et musique modérées par l'hôte `host.ts`), palette, launcher, tools, cozy, skilltree, onboarding).
- Conventions UI, i18n, thèmes : `mem:conventions`.
- 1.2 : `components/lite.tsx` (mode allégé : `useLite`, `Hint`, `Detail`, `More` ; `MenuMore` dans `Menu.tsx` ; `PageHeader`/`Field` s'adaptent seuls). Prefs : `lite`, `uiScale` (`useUiScale`), `devMode` (`useDevMode`, 7 appuis sur la version, pages `dev: true` dans `sections.ts`). Réglages : `features/settings/tabs.ts`. Projet HUB : `features/hub` (page `hub`, onglet de Projets ; `collab.ts` = partage `hub.*`). `lib/boardSpec.ts` dessine les schémas d'Artix. `lib/hub.ts`, `lib/devmode.ts` purs et testés. Chaînes anglaises manquantes : `node scripts/missing-en.mjs`.
